# 云南奶龙大学 · 跳转站

仿 [四川奶龙大学.cn](http://四川奶龙大学.cn/) 做的整活跳转页：访客进来先看一段动画，最后被送到**云南财经大学官网**。

站点名 **云南奶龙大学**，跳转目标 `https://www.ynufe.edu.cn/`。

主角是一只蓝色袋鼠玩偶：白底照片抠成透明图，当贴纸贴在校园照片上，最后被几条轮廓汇聚成云财校标里的古钱币。

## 文件

| 文件 | 作用 |

| `index.html` | 结构。场景与校标是内联 SVG；图片引用指向图床 |

| `preview/` | 各阶段效果图 |

零依赖、零构建：双击 `index.html` 就能跑。

## 换形象

抠图与轮廓提取都脚本化了：

```bash
python3 tools/cutout.py 215 700 daishu 24        # 白底照片 → 透明 daishu.png / daishu.webp
python3 tools/extract_outline.py daishu.png 220  # alpha → 220 点轮廓，写入 tools/outline_out.js
python3 tools/upload.py                          # 传到图床并刷新 tools/cdn-urls.txt
```

然后把 `tools/outline_out.js` 里的 `NAILONG` 数组和 `main` 那一行贴回 `shapes.js`。

### 抠图：为什么不能一把阈值切完

`daishu.jpg` 是白棚拍的毛绒玩偶，背景不是数学纯白 —— 底部还压着一层 208~250 连续渐变的地面浅灰，没有硬边。所以 `tools/cutout.py` 用两级策略：

1. 亮度阈值 215 圈出确定背景，**只保留与画面边界连通的白区**。主体内部的白色（眼白、胸前徽标白底、米白腹部）不与外界连通，因此天然保住。
2. 再在「低饱和（sat ≤ 30）且不太暗（mn ≥ 185）」的像素上向外扩展 24 次迭代，把地面浅灰吃掉。24 是实测拐点：底部残渣从 2822 px 降到 302 px，而米白腹部的保留量**恒定不变**（它被高饱和的蓝/黄身体围住，扩展根本走不进去）。

不能用 `cv2.floodFill` 的 `loDiff/upDiff`：那是「与相邻像素比」，JPEG 软边提供了连续的渐变链，容差开到 14 就顺着绒毛爬进主体内部，实测主体只剩 0.4%。

抠完再按 alpha 做一次反混合，把边缘像素里混进去的白色减掉，所以没有白边。

### 轮廓：为什么不用射线法

射线法要求剪影对质心是星形（每个方向只有一条边界）。原来的奶龙圆头圆脑、手臂张开，接近星形，所以射线法能到 IoU 0.9918。这只袋鼠是坐姿 + 翘尾巴，尾巴与身体之间、两耳之间有深凹口，射线法会把凹口全部拉直 —— 实测 IoU 只剩 **0.56**。

`tools/extract_outline.py` 改成：`findContours` 取真实外轮廓 → 起点对齐到正上方 → 沿周长弧长均匀取 220 点 → 统一顺时针。顶点顺序、起点相位、旋转方向三者都与 `shapes.js` 的其它形状一致，补间时逐点对应不打结，IoU **0.9954**。

换图后要改 `shapes.js` 里两个数：`main.at`（剪影质心在图片内的相对位置，当前 `[0.4989, 0.5875]`）、`main.k`（轮廓直径 ÷ 图片高度，当前 `1.2103`）。

### 方足布的比例

校标里那枚铲形古钱币，轮廓不是凭手感画的，按战国方足布的考古实测中位值换算（通高 45mm、足宽 25mm、首宽 17mm、裆深 14mm、裆口宽 6mm）：

- 高宽比 1.80
- 首宽占最大宽 65%（首是方形凸台；早先做成 33% 会读成「脖子」）
- 裆深占总高 31%，裆口占最大宽 24%

前几版围着「像不像裤子」反复调，其实没有硬锚；锚定实测比例后形状本身可核对。另外首点必须落在对称轴（顶边中点）上 —— `resample` 是按弧长等分取 220 点的，起点一旦偏在顶边某一端，采样点整体偏移半个间距，左右就镜像不严（渲染成「一侧腰线鼓包」）。起点在轴上时 i 与 220−i 恰好互为镜像，实测偏差 1e-15。

### 卡片轮廓对不上怎么办

`shapes.js` 里 `'1'`~`'4'` 的 `at` 与 `k` 是按「贴纸居中、占照片高度六成」估的。贴纸站在舞台的哪个位置由 `style.css` 的 `.nl{left:44%;top:52%;width:22%}` 决定，两者可能要一起微调。

## 本地预览

```bash
python3 -m http.server 8899
# 打开 http://127.0.0.1:8899/
```

调试参数（可叠加）：`?stay=1` 走完动画不跳转 · `?final=1` 直接呈现最终画面 · `?final=1&probe=1` 叠加红色虚线探针，核对补间终点与校标上的布币是否重合。

截图验证用 `tools/shoot.py`（CDP 真实时间驱动）：

```bash
python3 tools/shoot.py http://127.0.0.1:8899/ 1440 900 /tmp/shot 0,3.5,7,10.5,13.5,17.5
```

别用 `--virtual-time-budget`：虚拟时间只推进定时器，rAF 和 CSS transition 都不走，抓出来是假帧（实测只有 2 帧 / 17ms）。

## 动画时序（约 17 秒）

1. 图书馆照片入画
2. 贴纸被「抠出来」：画面压暗，轮廓发光并抖一下
3. 脱离场景，场景淡出
4. 校园其它四处的贴纸以拍立得卡片飞入
5. 五条轮廓汇聚成一枚古钱（外圆内方，方孔从中心展开）
6. 古钱继续补间成云财校标里的**方足布** —— 校标释义写着「钱币图案形似汉字‘人’」，方孔在这一步收缩消失
7. 校标升起：地球圆与经纬线、外环、1951、中英文校名依次描出
8. 四张便签贴上，进度条走完 7 秒 → 云财蓝的圆扩散铺满 → 跳转官网

四张便签：本科招生网、云南咖啡商学院揭牌、云财兔宝、**猫猫学长（猫狗相伴）**。点任意一张都会暂停跳转并弹出说明。

## 部署到 云南奶龙学院.icu

域名 punycode：`xn--9kq39il8fy5bf69jmtl.icu`

> 站名是「云南奶龙**大学**」，域名是「云南奶龙**学院**」，两者对不上。要么换域名，要么把 `index.html` 里的站名改回「学院」。

**静态托管**（最省事）

- Cloudflare Pages / Vercel / Netlify：整个目录拖上去，再绑定自定义域名
- 自己的服务器：

```nginx
server {
    listen 80;
    server_name xn--9kq39il8fy5bf69jmtl.icu;
    root /var/www/yunnan-nailong;
    index index.html;
    location / { try_files $uri $uri/ /index.html; }
}
```

**DNS**：`@` 配 A 记录指向服务器 IP，`www` 配 CNAME；中文域名建议把 punycode 形式也一起配上。

**HTTPS**：

```bash
certbot --nginx -d xn--9kq39il8fy5bf69jmtl.icu
```

## 跳转行为

- 最终画面停留 7 秒（进度条即计时）后 `location.replace` 到 `https://www.ynufe.edu.cn/`
- 点任意便签会**暂停**自动跳转（状态文字变「已暂停跳转」），可点「直接前往」手动走
- 20 秒硬兜底：任何环节卡住都会把访客送到官网
- 禁用 JS 时由 `<noscript>` 里的 meta refresh 兜底
- 尊重 `prefers-reduced-motion`：开启后动画缩短、不补间
